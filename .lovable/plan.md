# Company-facing Slack success page

## Goal
Turn the Slack connection confirmation into a polished brand moment for company owners: immediately confirm success, introduce Asmi’s value, and make the next action obvious.

## Content hierarchy
- Lead with the established Asmi wordmark at meaningful brand scale.
- Use the corrected core pitch: **“Your AI for Real World Chores.”**
- Keep “Asmi is ready in Slack” as the clear success confirmation, but subordinate it to the brand pitch.
- Replace generic integration copy with one concise company-facing line about delegating real-world calls, messages, bookings, and follow-ups from Slack.
- Retain the connected workspace name, approved-access reassurance, and permission-control message.
- Keep only two actions: **Open Asmi** and **Close this window**.

## Visual direction
- Preserve the selected asymmetric desktop handoff and responsive mobile stack.
- Make the left side feel like a premium campaign moment: larger Asmi identity, bold pitch, and restrained Asmi-to-Slack connection mark.
- Keep the right side compact and operational: workspace confirmation, permission summary, and actions.
- Continue the existing moonlit plum, ivory, amber, and success-green palette with Sora/Manrope typography, restrained motion, and no decorative clutter.
- Use the current italic Asmi wordmark as the official logo treatment; no invented icon or replacement mark.

## Technical details
- Update only the Slack success route’s copy, hierarchy, metadata, and layout styling.
- Keep the existing workspace query parameter and close-window fallback behavior.
- Preserve semantic tokens and the current shared design system.
- Verify desktop and mobile layouts for legibility, overflow, and runtime errors.
